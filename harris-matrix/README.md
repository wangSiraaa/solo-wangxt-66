# 地层矩阵编辑台（Harris Matrix Workbench）

面向考古记录员的纯浏览器地层矩阵整理工具：把堆积、切割、填充关系整理为可检查的有向矩阵，所有数据只存本机 IndexedDB，不上传任何现场资料。

## 运行

```bash
npm install
npm run dev      # 开发
npm run build    # 类型检查 + 构建
npm test         # 图算法自测（成环/传递约简/偏序摘要/布局）
```

## 技术栈

Vue 3 + TypeScript · Graphology（有向关系与图算法）· Cytoscape.js（矩阵绘制）· Dexie（IndexedDB 工程库）

## 设计要点

- **身份与位置分离**：层位（`loci`）只存身份；画布坐标在 `positions` 表，按 id 关联，拖动后落库。
- **编号体系按探方独立**：层位 id = `探方:编号`（如 `TG1:105` 与 `TG2:105` 是同号不同层位），v1 数据自动迁移入 TG1。
- **三类判断分开保存**：关系行带 `layer`（原始观察 / 推断）与 `status`（有效 / 矛盾 / 已撤销）；撤销判断另写 `revocations` 表，记录永不删除。
- **成环检测**：新增有向关系前用 BFS 检测 `to →…→ from` 回边，返回完整环路径并在画布上标红定位；用户可选择拒绝写入或留档为「矛盾记录」（不进图）。
- **同期关联不是边**：`association` 类型只存档，原始视图中以无向虚线呈现，绝不进入有向图、不参与成环与传递约简。
- **简化只隐藏**：简化视图通过传递约简隐藏传递边，关系与证据记录原样保留，可随时切回原始关系视图。
- **批量操作可撤销**：所有变更以批次（含完整快照）记入 `batches` 表；撤销批次逆序回放反向操作，关系与其证据引用一起恢复。
- **偏序可校验**：导出 JSON 附偏序摘要（节点→可达集），导入后重算比对，界面上给出「偏序未改变 ✓」。

## 跨探方关联假设

- **互不污染**：假设（`hypotheses`）与关联项（`hypothesisLinks`，若干层位视为同时期）独立成表；评估是纯函数（`evaluateChronology`），只读底稿，未确认的关联没有任何写回共同底稿的路径。
- **统一数值年代轴**：内部轴 `t = −calBP`（越大越晚）；未知端点为 `null`，绝不用 0 代替。TPQ（不早于）沿地层链向晚传播，TAQ（不晚于）向早传播；关联组取成员区间交集。
- **可复现的矛盾依据**：假设导致先后成环（关联项成员间存在先后链，含多项串联成环）或年代区间无交集时，输出一组仅由引用构成的依据——关系 id / 路径、关联项 id、测年证据 id 及传播路径；矛盾 id 由内容决定，同数据反复评估结果一致。只展示，不自动修正原始记录。
- **逐项比较**：「对比」页签逐项列出两个假设的关联项差异（独有/共有）、每个层位的阶段归属（Ph1 最早）差异与各自矛盾。
- **证据只被引用**：测年证据全库唯一一份（`dating` 表），假设与矛盾依据只存其 id；后来补入的证据自动参与传播，删除假设不影响证据与底稿。

## 示例工程

「载入示例」一键生成：TG1/TG2 两个编号独立的探方（含**同号不同层位** TG1·105 / TG2·105）、灰坑/柱洞/扰坑三个**切割事件**及填充、探方外**孤立层位** TG1·110、一对**互相矛盾的观察**（105↔106）、4 条**测年证据**，以及两个**关联假设**——甲方案（灰烬层≈文化层，自洽）与乙方案（同号对应：年代无交集 + 柱洞≈地面成环，用于演示矛盾依据）。

## 数据表（Dexie / IndexedDB）

| 表 | 内容 |
| --- | --- |
| `loci` | 层位身份（探方、编号、名称、类型） |
| `positions` | 画布坐标（与身份分离） |
| `relations` | 全部关系（观察/推断 × 有效/矛盾/已撤销） |
| `evidence` | 证据，挂在关系上 |
| `revocations` | 撤销判断日志 |
| `batches` | 操作批次（含变更快照，供撤销） |
| `dating` | 测年证据（唯一一份，只被引用） |
| `hypotheses` / `hypothesisLinks` | 关联假设与关联项（与底稿隔离） |
