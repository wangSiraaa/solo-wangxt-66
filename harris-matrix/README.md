# 地层矩阵编辑台（Harris Matrix Workbench）

面向考古记录员的纯浏览器地层矩阵整理工具：把堆积、切割、填充关系整理为可检查的有向矩阵，所有数据只存本机 IndexedDB，不上传任何现场资料。

## 运行

```bash
npm install
npm run dev      # 开发
npm run build    # 类型检查 + 构建
npm test         # 图算法自测（成环/传递约简/偏序摘要/布局）
```

## 技术栈

Vue 3 + TypeScript · Graphology（有向关系与图算法）· Cytoscape.js（矩阵绘制）· Dexie（IndexedDB 工程库）

## 设计要点

- **身份与位置分离**：层位（`loci`）只存身份；画布坐标在 `positions` 表，按 id 关联，拖动后落库。
- **三类判断分开保存**：关系行带 `layer`（原始观察 / 推断）与 `status`（有效 / 矛盾 / 已撤销）；撤销判断另写 `revocations` 表，记录永不删除。
- **成环检测**：新增有向关系前用 BFS 检测 `to →…→ from` 回边，返回完整环路径并在画布上标红定位；用户可选择拒绝写入或留档为「矛盾记录」（不进图）。
- **同期关联不是边**：`association` 类型只存档，原始视图中以无向虚线呈现，绝不进入有向图、不参与成环与传递约简。
- **简化只隐藏**：简化视图通过传递约简隐藏传递边，关系与证据记录原样保留，可随时切回原始关系视图。
- **批量操作可撤销**：所有变更以批次（含完整快照）记入 `batches` 表；撤销批次逆序回放反向操作，关系与其证据引用一起恢复。
- **偏序可校验**：导出 JSON 附偏序摘要（节点→可达集），导入后重算比对，界面上给出「偏序未改变 ✓」。

## 示例工程

「载入示例」一键生成一个探方：灰坑/柱洞/扰坑三个**切割事件**（104、108、112）及其填充，探方外**孤立层位 110**（虚线红框节点），以及一对**互相矛盾的观察**（105↔106，后者留档为矛盾记录，附 6/12 与 6/14 两条田野记录证据）。

## 数据表（Dexie / IndexedDB）

| 表 | 内容 |
| --- | --- |
| `loci` | 层位身份（编号、名称、类型） |
| `positions` | 画布坐标（与身份分离） |
| `relations` | 全部关系（观察/推断 × 有效/矛盾/已撤销） |
| `evidence` | 证据，挂在关系上 |
| `revocations` | 撤销判断日志 |
| `batches` | 操作批次（含变更快照，供撤销） |
